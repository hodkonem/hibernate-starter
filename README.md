Hibernate Starter

Учебный сервис, предназначенный для изучения механизмов работы ORM-уровня на базе Hibernate ORM 7.x и взаимодействия с реляционными СУБД. Проект используется для отработки корпоративных подходов к реализации слоя доступа к данным и проверки технических решений на локальном окружении.

1. Назначение

Проект предназначен для:

изучения конфигурации и возможностей Hibernate ORM 7.x;

отработки принципов маппинга объектов в реляционные структуры;

выполнения базовых операций управления данными (CRUD);

анализа SQL, генерируемого ORM;

исследования моделей транзакций.

Проект не является продуктовой системой и используется исключительно для учебных и исследовательских задач.

4. Структура проекта
   src
   ├── main
   │    ├── java
   │    │    └── ru/...           # доменные модели, конфигурация ORM
   │    └── resources
   │         └── hibernate.cfg.xml
   └── test
   └── java                  # модульные тесты


Структура проекта соответствует внутреннему стандарту разделения на слои:

domain — доменные сущности (JPA-модели);

repository / dao — операции доступа к данным;

config — конфигурационные классы ORM.

5. Соглашения по разработке и код-стайлу

Используется стандартное оформление кода IntelliJ IDEA или Google Java Style Guide.

Имена пакетов формируются по шаблону ru.<company>.<module>.

Для моделей данных применяются JPA-аннотации с размещением над полями.

Все сущности обязаны содержать:

идентификатор (@Id);

стратегию генерации ключей;

публичный конструктор без аргументов.

Для устранения шаблонного кода используется Lombok.

Транзакции контролируются программно или через декларативный подход (по мере роста проекта).

6. Политика логирования

Логирование используется в информационных целях для анализа SQL:

<property name="hibernate.show_sql">true</property>
<property name="hibernate.format_sql">true</property>


Рекомендации:

Для локальной разработки допускается уровень логирования DEBUG.

Для тестовых сред — INFO.

В продуктивных средах логирование SQL отключается, если нет отдельного согласования.

7. Настройка окружения

Создать базу данных PostgreSQL:

CREATE DATABASE hibernate_starter;


Указать параметры подключения в hibernate.cfg.xml:

<property name="hibernate.connection.url">jdbc:postgresql://localhost:5432/hibernate_starter</property>
<property name="hibernate.connection.username">postgres</property>
<property name="hibernate.connection.password">password</property>


Сборка проекта:

./gradlew build


Запуск:

через IDE либо через выполнение соответствующего main-класса.
